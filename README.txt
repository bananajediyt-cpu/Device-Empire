DEVICE EMPIRE - GitHub Pages bundle

Files:
  index.html  the game
  logo.svg    the logo (also used as the tab icon)

How to put it on GitHub Pages:
1. Make a new PUBLIC repository on github.com.
2. Click Add file > Upload files and drag in index.html and logo.svg
   (unzip this bundle first). Click Commit changes.
3. Go to Settings > Pages. Under Build and deployment choose
   "Deploy from a branch", pick the main branch and the / (root) folder, then Save.
4. After a minute or two your game is live at
   https://YOURUSERNAME.github.io/REPOSITORYNAME/
